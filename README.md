# 戴夫的后院 · Dave's Backyard

植物大战僵尸风格的 3D 第一人称射击小游戏，纯 Web 实现，iPhone / iPad / 电脑浏览器都能直接玩。

你是戴夫，手里拿的不是枪，而是一株株会射击的植物；冲上来的是成群的僵尸。

## 快速开始

```bash
npm install
npm run dev
```

启动后终端会打印局域网地址（例如 `http://192.168.1.8:5173/`）。
手机 / iPad 与本机连同一个 Wi-Fi，用 Safari 打开这个地址即可。

生产构建：

```bash
npm run build     # 输出到 dist/
npm run preview   # 本地预览构建产物
```

`dist/` 是一份纯静态站点，丢到任意静态托管（Nginx、GitHub Pages、Vercel……）都能跑。

> 注意：不能直接双击 `dist/index.html` 用 `file://` 打开，浏览器的模块 / 音频限制会拦截，必须用 HTTP 服务。

## 操作方式（自动识别设备）

进入游戏时自动判断：粗指针 / 无 hover 设备（iPhone、iPad）用虚拟触屏控制；
有鼠标的设备（电脑）自动切换成经典 FPS 键鼠，并隐藏屏幕上的虚拟按键。

**iPhone / iPad**
- 左半屏任意位置按下：出现虚拟摇杆，拖动即可上下左右移动（松开自动回中）
- 右半屏拖动：转动视角瞄准（带触屏辅助瞄准）
- 右下 **开火**：按住连射；**跳**：跳跃
- 下方植物栏：点一下切换，玉米炮 / 樱桃需要消耗阳光
- 地上的植物走上去就会自动拾取，拾取后出现在第 5 格战利品位

**电脑**
- `W A S D` 移动，鼠标瞄准，左键射击，空格跳跃
- `1 2 3 4` 或点击底部植物栏切换植物；`5` / `Q` 切回捡到的战利品
- 点击开始后自动锁定鼠标；按 `Esc` 暂停，暂停界面的「继续战斗」会重新锁定

两种输入可以同时用（接键盘的 iPad 也能 WASD）。

## 玩法

- 进入游戏先选地图：**戴夫的后院**（经典草地）或 **雪地**（按 CS 的 fy_iceworld 复刻：田字四根高柱、两侧可跳矮墙、两端基地与成排地面武器）。
- 一波一波的僵尸从场地四周的泥土里钻出来，清完一波进入下一波，每 5 波出现一次巨人僵尸。
- 击杀僵尸掉落阳光，靠近会自动吸附并拾取；阳光是寒冰、樱桃和玉米加农炮的弹药。
- 地图上散落着会发光的植物，走上去就能拾取，附带一包弹药，打空后自动换回豌豆射手；越大的地图刷得越多。
- 生命值不会自动回满：脱战 7 秒后缓慢回复，每清一波额外回血。
- 爆头造成双倍伤害；击杀得分，清波有额外奖励。
- 死亡后进入结算界面，可以直接再来一局，也可以点「换地图」回主菜单。

| --- | --- | --- |
| 豌豆射手 | 初始 | 免费，无限弹药 |
| 寒冰射手 | 初始 | 3 阳光/发，命中减速 |
| 樱桃炸弹 | 初始 | 22 阳光/发，抛投爆炸 |
| 玉米加农炮 | 初始 | 40 阳光/发，即时命中 |
| 双发射手 | 地面拾取 | 一次两发，70 发 |
| 三线射手 | 地面拾取 | 三向散射，48 发 |
| 机枪射手 | 地面拾取 | 超高射速，140 发 |
| 仙人掌 | 地面拾取 | 一发穿透三只，40 发 |
| 西瓜投手 | 地面拾取 | 大范围爆炸，10 发 |
| 火爆辣椒 | 地面拾取 | 引燃一片，6 发 |

僵尸：普通僵尸、路障僵尸、铁桶僵尸，以及第 5 / 10 / 15… 波出现的巨人僵尸（顶部有独立血条）。

## 技术说明

- Three.js 实时 3D。僵尸是程序化生成的高细节人体模型（分层骨骼、可弯曲四肢、3D 五官、手部手指、帽子/铁桶/木棒），皮肤、布料与金属材质来自文生图模型生成的贴图，启动时合成为一张图集使用；其余场景与植物模型全部程序化建模，音效为 WebAudio 实时合成。
- 移动端适配：强制横竖屏布局、安全区、动态摇杆、多点触控、DPR 上限与自动降分辨率。
- 触屏辅助瞄准：准星进入目标锥形范围会自动吸附，准星变金色表示已锁定。
- 雪地的高低差：中央四根 9 × 9 米、约 3.6 米高的方形冰柱按田字排开，挡住视线且跳不上去；两侧矮墙约 0.85 米，可以跳上去站稳；四角砖台可以直接踏步走上去。
- 性能：约 110～250 个 draw call（僵尸各 10 个网格，雪地额外有拾取物与飘雪）；桌面 / iPad 开实时阴影，帧率不足时自动降低渲染分辨率。

## 小贴士

- iPhone 上建议「添加到主屏幕」再打开，可以全屏、没有地址栏，体验更接近 App。
- 首次点击「开始保卫后院」时才解锁音频（iOS 的限制），所以不要静音启动。
- 觉得难度不够？`src/config.js` 里可以调僵尸血量、速度、波次预算和植物伤害。
