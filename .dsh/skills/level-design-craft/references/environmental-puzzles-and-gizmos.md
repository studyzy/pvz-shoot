# 环境解谜、机关与防死锁设计指南 (Environmental Puzzles & Anti-Softlock)

> **来源与适用范围**：本页是书籍方法论、公开行业实践与仓库自定义启发式规则的二次整理；具体阈值必须结合品类、引擎和玩家测试校准。详见 [来源与校准规范](../../SOURCE_PROVENANCE.md)。


> 本手册提炼自《Portal》《The Legend of Zelda: Breath of the Wild / Tears of the Kingdom》《The Witness》《Inside》等空间解谜神作的设计心法，深度解析环境机关因果链（Causality Chains）、隐性解谜教学与防卡关死锁（Anti-Softlock）工程标准。

---

## 1. 空间解谜因果链模型 (The Causality Chain Model)

一个优雅的环境谜题不是生硬的“数独”或“拼图”，而是**利用物理常识与空间几何构建的因果互动系统**：

```mermaid
flowchart LR
    A[1. 视觉可见目标\nVisible Affordance\n(如: 对岸锁死的铁门)] --> B[2. 阻断因果线\nCausality Gap\n(如: 桥梁断裂 + 门缺少电源)]
    B --> C[3. 探索空间机关\nSpatial Gizmo\n(如: 导电水渠 + 铁箱 + 激光线)]
    C --> D[4. 状态切换与连通\nState Toggle\n(如: 移动铁箱联通电路)]
    D --> E[5. 顿悟解脱\nEureka Payoff\n(大门轰然开启!)]
```

### 核心解谜要素四元组：
1. **可感知物 (Affordance)**：玩家一眼就能猜出大致功能的物体（重物、水流、火把、反射镜面、风扇吹风口）。
2. **阻断线 (The Blockage)**：阻止玩家直接达成目标的物理障碍（距离过远、高空坠落、带电屏障、时间倒计时）。
3. **状态切换器 (State Toggle)**：改变环境物理属性的开关（拉杆、重力压板、激光折射、冰冻/熔化）。
4. **正反馈闭环 (Feedback Loop)**：机关被激活时，伴随震撼的机械轰鸣、指示灯变绿或水流漫灌，向玩家清晰确认“因果链已接通”。

## 2. 经典空间机关类型学 (Spatial Gizmo Typologies)

```
+-------------------------------------------------------------------------+
| [空间机关四大原型]                                                        |
|                                                                         |
|  1. 导流与连通型 (Flow / Circuit):                                      |
|     - 水流、激光束、电线、滚球轨道。                                    |
|     - 机制核心: 修复断裂的线路，将能源从源头 (Source) 导向终点 (Sink)。   |
|                                                                         |
|  2. 动量与投射型 (Momentum & Trajectory):                               |
|     - 弹射板、传送门无限坠落加速、重力摆锤。                            |
|     - 机制核心: 将重力势能转化为水平动能，突破超长水平峡谷。              |
|                                                                         |
|  3. 空间几何重构型 (Spatial Transformation):                             |
|     - 旋转房间 90°、水位升降改变浮力、光影透视对齐 (The Witness)。        |
|     - 机制核心: 改变重力方向或立足点高度，使原本不可达的高台变成地面。   |
|                                                                         |
|  4. 时钟与同步协作型 (Timing & Sync):                                   |
|     - 倒计时闸门、双人同时踩下压力板、分身时间回溯 (Braid)。             |
|     - 机制核心: 规划精准的操作序列与时间窗口。                          |

```

## 3. 隐性解谜教学 4 步法则 (Implicit Puzzle Pacing)

严禁通过弹窗文字教玩家如何解谜。遵循任天堂与 Valve 的**“无文字 4 步认知递进”**：

| 阶段 | 场景设计 | 玩家心智模型 | 容错与惩罚 |
| :--- | :--- | :--- | :--- |
| **1. 安全试错 (Safety Sandbox)** | 封闭小房间内只有一个按键和一个门。除按下按键外无法离开。 | “按这个键门会开！”（单点机制学习） | 零惩罚，绝无死亡危险 |
| **2. 局部干扰 (Introduced Complication)** | 必须在 5 秒内从按键处跑向大门，但中间多了一堵矮墙。 | “需要结合翻越动作在时限内通过。” | 失败仅重置机关，无死亡 |
| **3. 空间复合 (Spatial Layering)** | 大门在对岸，需要先将箱子推到水里当浮桥，再拉动开关。 | “将先前学到的两种机制组合使用。” | 轻度惩罚（落水扣微量血） |
| **4. 逆向思维 (Subversion / Climax)** | 开关拉动后大门反向关闭，需要用重物卡住齿轮或借助激光反射反向触发。 | “打破常规逻辑，产生‘原来还能这样’的顿悟！” | 高潮成就感 |

## 4. 防卡关与防死锁协议 (Anti-Softlock Protocol)

关卡设计中最恶劣的事故是**“死锁（Softlock）”**——玩家因为操作失误导致关键道具丢失或卡在无法退出的地形中，且无法重置，只能强行删档或读档。

```
                    [ 必须坚守的防死锁五大戒律 ]
                                  |
     +----------------------------+----------------------------+
     |                                                         |
[1. 物理道具深渊重生]                                     [2. 箱子死角防卡死]
道具掉入悬崖/水底后，                                     当推拉箱子被推入墙角导致无法拉出时，
3 秒内自动在初始底座刷出。                                房间入口必须提供 "重置拉杆" 或一键自毁按键。
     |                                                         |
[3. 不可逆落差单向防护]                                   [4. 关键钥匙防销毁]
在跳入单向不可逆房间 (Dropdown) 之前，                     剧情关键钥匙或芯片严禁设计为
必须确保身上已收集齐全前置必需道具。                       可被玩家意外分解/丢弃/被炸毁的实体。
     |                                                         |
     +----------------------------+----------------------------+
                                  |
                      [5. 安全自毁重开机制]
           若玩家仍卡入非预期几何缝隙，提供 "原地自杀/返回上个检查点" 选项。
```

### 防死锁排查自检表：
- [ ] **所有物理 RigidBody 道具**是否有 `OutOfBounds` 销毁与复活触发器（Respawn Trigger）？
- [ ] **多状态机关**在断电或读档后，是否能保持一致的持久化状态（Persistence）？
- [ ] **移动平台**是否具备防夹死挤压判定（Crush Detection）？（挤压时应自动反向运行或将玩家推向安全侧）。
