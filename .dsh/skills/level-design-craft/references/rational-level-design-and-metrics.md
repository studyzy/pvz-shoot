# 理性关卡设计与度量规范指南 (Rational Level Design & Metrics)

> **来源与适用范围**：本页是书籍方法论、公开行业实践与仓库自定义启发式规则的二次整理；具体阈值必须结合品类、引擎和玩家测试校准。详见 [来源与校准规范](../../SOURCE_PROVENANCE.md)。


> 本手册整理了公开讨论中的**理性关卡设计（Rational Level Design, RLD）**思想，并加入仓库自定义度量启发式。它用于提高白盒阶段的一致性，不代表任何工作室的私有内部规范，也不能替代引擎实测与玩家测试。

## 1. 关卡度量衡系统 (Level Design Metrics)

**度量（Metrics）是关卡设计的物理宪法**。所有白模（Blockout / Graybox）搭建必须严苛匹配主角的动机尺寸，严禁脱离度量随意拉伸几何体。

### 3A 拟真人型标准化度量速查表 (标准米制模型：身高 1.8m)

```
                       [ 顶部天花板 Clearance >= 2.4m ]
                                     |
    +--------------------------------+--------------------------------+
    |                                                                 |
    |   [全身掩体 High Cover]          [玩家站立 1.8m]                 |
    |   高度: 1.9m ~ 2.2m              眼睛视平线: 1.65m               |
    |   (完全阻断所有直射子弹)         宽度/胶囊体: 0.8m               |
    |                                                                 |
    |   [半身掩体 Low Cover]           [翻越/攀爬 Mantle/Vault]        |
    |   高度: 0.9m ~ 1.1m              极限翻越高度: 1.2m              |
    |   (可射击/可翻越/受迫蹲下)       极限抓边缘高度: 2.5m            |
    |                                                                 |
    |   [钻爬通道 Crouch / Crawl]      [台阶与楼梯 Stairs]             |
    |   蹲伏高度: 1.2m ~ 1.4m          单级踏步高: 0.15m ~ 0.2m        |

    |                                                                 |
    +--------------------------------+--------------------------------+
```

### 关键位移动力学度量表

| 动作类型 | 标准度量 (标准 3A 角色) | 极限安全裕度 (Safe Tolerance) | 关卡应用规范 |
| :--- | :--- | :--- | :--- |
| **常规平地跳跃距离** | $2.5\text{m} \sim 3.0\text{m}$ | 保留 $0.5\text{m}$ 宽容带 | 基础平台跳跃间距 |
| **冲刺起跳距离** | $4.0\text{m} \sim 5.0\text{m}$ | 保留 $0.8\text{m}$ 宽容带 | 高风险悬崖、大跨度断桥 |
| **单人通过门洞宽度** | 最小 $1.0\text{m}$ (标准 $1.2\text{m}$) | 遇敌交火区建议 $\ge 2.0\text{m}$ | 防止镜头穿模与卡角色 |
| **双人/AI伴随走廊宽** | 最小 $2.4\text{m} \sim 3.0\text{m}$ | 确保转身与 AI 寻路不顶撞 | 战术射击室内场景 |
| **掩体到掩体滑铲距离**| $3.5\text{m} \sim 4.5\text{m}$ | 刚好衔接两个半身掩体 | 遭遇战防线推进节拍 |

## 2. 宏观心流 vs 微观心流 (Macro Flow vs Micro Flow)

```mermaid
flowchart TD
    subgraph 宏观心流 Macro Flow (全局感知 5~15 分钟)
    M1[关卡起始点] --> M2[宏观地标 1: 钟楼]
    M2 --> M3[分流中继站: 庭院]
    M3 --> M4[核心收束点: 城堡大门]
    end

    subgraph 微观心流 Micro Flow (局部感知 1~5 秒)
    M2 -.-> U1[发现掩体]
    U1 --> U2[翻越矮墙]
    U2 --> U3[消音击杀巡逻兵]
    U3 --> U4[捡取钥匙卡]
    end
```

- **Macro Flow（宏观动线）**：
  - 关注整张地图的拓扑结构、里程碑、区域转换与大节奏（起伏张力）。
  - 核心指标：**玩家是否明确当前大目标？是否理解自己在世界中的相对位置？**
- **Micro Flow（微观动作流）**：
  - 关注具体 10 米范围内的按键序列、跳跃节奏、掩体转移、射击窗口。
  - 核心指标：**每个动作之间的衔接是否顺滑？操作容错窗口是否符合心流？**

## 3. 原子化挑战与认知负荷理论 (Atomic Challenges & Cognitive Load)

育碧 RLD 体系的核心精髓在于：**将任何复杂的关卡体验解构为互不干扰的“原子能力（Atomic Abilities）”，再通过严格计算玩家的认知负荷进行层叠**。

### 原子挑战层叠矩阵 (The Layering Matrix)

```
[4 级超频负荷: 极限 Boss / 关底逃亡] = [基础移动] + [动态环境危险] + [高压追兵] + [严格倒计时] (负荷值 100%)
                     ^
[3 级复合挑战: 进阶战斗 / 复杂谜题] = [基础移动] + [移动平台/机关] + [远程狙击手压制] (负荷值 70%)
                     ^
[2 级组合挑战: 机制拓展 / 引入干扰] = [基础移动] + [轻度环境障碍 (如滑冰/强风)] (负荷值 40%)
                     ^
[1 级原子基石: 机制教学 / 安全沙盒] = [单点动作教学 (如单次二段跳跃)] (负荷值 20%)
```

### 认知负荷计算法则（杜绝设计事故）：

1. **同维负荷冲突定律**：
   - 严禁在同一秒内向玩家索取两项互斥的高精度输入（如：在 $0.2\text{s}$ 内同时要求高精度空中转向 + 远距离爆头射击）。
2. **新机制引入铁律**：
   - **当引入全新原子挑战（New Atomic Mechanic）时，环境负荷与其他干扰敌人必须归零（降至 1 级）**。直到玩家完成至少 2 次无干扰正反馈，方可开始增加干扰层。

## 4. 难度阶梯与理性曲线 (Rational Difficulty Curves)

关卡难度不应是线性上升的直角三角形，而应是具有呼吸感的**锯齿递增曲线（Sawtooth Progression）**：

```
难度指数
  ^
  |               /|  (关底高潮 Climax)
  |       /|     / |
  |      / |    /  |
  |  /| /  |   /   |
  | / |/   |  /    |
  |/  (释放)| /     | (大释放 Cool-down)
  +-------------------------> 关卡推进流程 (时间/距离)
   [区域1]  [区域2]   [区域3]
```

- **每次高潮挑战（Peak Challenge）后，必须强制插入 15~45 秒的低负荷探索区（Looting/Story Room）**。
- 如果连续 3 个遭遇战没有提供张力释放区，玩家将在第 8 分钟进入感知疲劳，导致操作失误率陡增并产生挫败退游。
