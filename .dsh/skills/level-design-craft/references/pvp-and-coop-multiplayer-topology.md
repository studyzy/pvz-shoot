# 多人竞技与合作关卡拓扑指南 (PvP & Co-op Multiplayer Topology)

> **来源与适用范围**：本页是书籍方法论、公开行业实践与仓库自定义启发式规则的二次整理；具体阈值必须结合品类、引擎和玩家测试校准。详见 [来源与校准规范](../../SOURCE_PROVENANCE.md)。


> 本手册提炼自《Counter-Strike: Global Offensive》《Call of Duty》《Overwatch》《Left 4 Dead》《It Takes Two》《Portal 2》等竞技与合作大作的经典拓扑心法，解析 PvP 竞技场三路结构、接触交火时间（TTE）、转角优势角与 Co-op 双人协同空间设计。

---

## 1. PvP 竞技场三路拓扑与中路控制 (The Classic Three-Lane Layout)

90% 的竞技射击与 MOBA 经典地图（如 CS 的 de_dust2, de_mirage，CoD 的 Raid）均基于**“三路两转（Three Lanes & Two Rotations）”**黄金骨架：

```
     [ 阵营 A 出生点 (Team A Spawn) ]
                 |
     +-----------+-----------+
     |           |           |
[左路 A-Lane] [中路 Mid]  [右路 B-Lane]
     |           |           |
     |     [中路争夺区]       |   <--- 提供全图最高的俯瞰视野与最快转点通道 (High Risk, High Reward)
     |    (Mid Control)      |
     +-----------+-----------+
     |     (双向旋转通道)     |   <--- 连接各路的横向快速转点通道 (Connector / Rotation Alley)
     |           |           |
     +-----------+-----------+
                 |
     [ 阵营 B 出生点 (Team B Spawn) ]
```

### 三路结构核心设计指标：
1. **中路战略价值 (Mid Control Dominance)**：
   - 占领中路的队伍拥有快速向左/右两条主战线增援包抄的特权（Rotational Advantage）。
2. **交火遭遇时间对称性 (Time-to-Encounter, TTE)**：
   - 从双方出生点全速奔跑抵达交火接触点（Chokepoints）的时间**误差必须在 $\pm 0.5$ 秒以内**。
   - 防守方可比进攻方早 $1.0\sim1.5$ 秒抵达架枪点，以抵消攻方的人数集火优势。

## 2. 几何视线角与转角优势 (Sightline Angles & Right-Hand Peek)

```
                              [ 敌方防守者 Defender ]
                                        |
     +----------------------------------+
     | 墙体 (Corner)
     |
     |           [ 视线几何视锥 Sightline Ray ]
     |         /
     |       /   <--- 离墙角越远的玩家，越先看到对方的身体边缘！
     |     /          (Angle Advantage: Distance to Cover)
     |   /
     | v
[ 进攻者 Attacker (贴墙走) ]
(身体已暴露，但视野仍被墙角遮挡 - 劣势!)
```

### 必须把控的几何对战法则：
1. **离墙距离优势（Angle Advantage）**：
   - 离转角越远的一方拥有更宽广的视锥，能在不露头的情况下更早发现贴墙走的目标。
2. **右手持枪转角（Right-Hand Peek）**：
   - 大多数 TPS/FPS 角色为右手持枪。**从掩体右侧探头（Peek Right）比从左侧探头暴露更少的身体截面积**。关卡两端必须保持掩体朝向的对称平衡。
3. **爆头线高度一致性（Headshot Line Continuity）**：
   - 地面坡度与台阶必须平缓，严禁在主交火线上设置随机起伏的小坑洼，确保预瞄（Crosshair Placement）的竞技纯粹度。

## 3. 重生点保护与反压制 (Spawn Safety & Spawn Flipping)

多人地图最破坏体验的现象是**“堵家压制（Spawn Trapping / Camping）”**：

```
               [ 基地安全防御区 (Protected Spawn Hub) ]
                                  |
     +----------------------------+----------------------------+
     |                                                         |
[1. 至少 3 个离散出口]                                    [2. 重生点动态翻转]
严禁单门出口！必须提供                                    当敌方突入本方半场 > 60% 深度时，
左、中、右 3 个独立的掩体出口。                           系统自动将己方重生点翻转至地图对侧。
     |                                                         |
[3. 出口高台与单向火力优势]                                [4. 视线阻隔防穿透]
基地出口处设置高台或单向防弹玻璃，                         严禁从地图中远距离直接用狙击枪
允许重生玩家安全扫射外围蹲点敌人。                         一眼望进敌人重生点大门。
```

## 4. Co-op 双人合作空间关卡设计 (Co-op Spatial Topology)

在双人协作关卡（如《双人成行》《传送门 2》）中，关卡设计的核心是**“强制分工与视线互通”**：

```
+-------------------------------------------------------------------------+
| [Co-op 经典分离式协作空间 Separated Collaboration]                       |
|                                                                         |
|  [玩家 A 区域: 控制室高台 (Refuge)]      [玩家 B 区域: 机械迷宫地面 (Arena)]   |
|  - 拥有全景俯瞰视野 (Prospect)          - 身处迷宫内部，视线受限              |
|  - 负责操作吊车/拉闸/关闭电网           - 负责搬运核心道具/击杀巡逻敌人       |
|                                                                         |
|               =============================================             |
|               [ 防弹隔音玻璃 / 激光网格 (物理阻隔但视线互通)]             |
|               =============================================             |
|                                                                         |
|  - 机制核心: 玩家 A 成为玩家 B 的 "眼睛"，双方必须通过实时语言/标记沟通!  |
+-------------------------------------------------------------------------+
```

### Co-op 关卡三大黄金拓扑原型：
1. **物理阻隔 + 视线互通（Visual Link, Physical Barrier）**：
   - 两人身处两个平行走廊，通过中间的透明玻璃互相看到对方的机关与敌人，一人拉动开关为另一人开路。
2. **互为锚点与接力推进（Leapfrogging Anchors）**：
   - 玩家 A 站上压力板激活升降梯，玩家 B 乘坐升降梯抵达高处拉下挂梯，接应玩家 A 上升。
3. **非对称能力互补（Asymmetric Synergies）**：
   - 一人手持重盾吸收火力开路，另一人紧跟身后专注输出或解密。空间必须提供恰好容纳双人推进的“盾防通道”。
