# 实战设计模板与诊断体检量表 (Templates & Diagnostic Rubrics)

> **来源与适用范围**：本页是书籍方法论、公开行业实践与仓库自定义启发式规则的二次整理；具体阈值必须结合品类、引擎和玩家测试校准。详见 [来源与校准规范](../../SOURCE_PROVENANCE.md)。


> 本手册提供了关卡设计实战中可直接复用的**一页纸 LDD 关卡策划卡、白模度量表、遭遇战节拍表**，以及针对现有关卡的**6 维健康度雷达体检表与迷路外科手术排查清单**。

## 模板 2：白模度量规范核对卡 (Blockout Metrics Card)

```markdown
### 白模尺寸与度量基准 (Metrics Check)
- [ ] **站立/潜行高度**：站立 $1.8\text{m}$，眼睛 $1.65\text{m}$，蹲伏 $1.2\text{m}$。
- [ ] **掩体高度**：全身掩体 $\ge 2.0\text{m}$，半身掩体 $1.0\text{m} \pm 0.1\text{m}$。
- [ ] **跳跃间距**：常规平跳 $2.8\text{m}$，极限冲刺跳 $4.5\text{m}$（落点保留 $0.5\text{m}$ 宽容带）。
- [ ] **通道与门洞**：主战区门宽 $\ge 2.2\text{m}$，探索通道宽 $\ge 1.4\text{m}$，天花板净高 $\ge 2.6\text{m}$。
- [ ] **视线切断物**：战区中心主遮挡物高度 $\ge 3.0\text{m}$，宽度 $\ge 5.0\text{m}$，杜绝全图贯穿枪线。
```

```markdown
# 遭遇战设计卡：[战区名称]

## 1. 空间与战术要素
- **入场侦察点 (Perch Entry)**：[描述：二楼通风管道格栅出口，高度 3.5m，可俯瞰全图]
- **渗透路线规划**：
  - 【路线 A - 潜行】：左侧下水道水沟 -> 潜行至发电机房关闭探照灯。
  - 【路线 B - 强攻】：中央废弃集装箱掩体链 -> 夺取重机枪固定阵地。
  - 【路线 C - 制高点】：右侧铁梯爬上塔吊 -> 反狙击敌方哨兵。
- **脱战回环 (Cat-and-Mouse Loop)**：[描述：利用 3 个集装箱拐角与 2 处可钻爬管道，支持丢失敌人视线重置潜行]

## 2. 敌情波次编排 (Enemy Waves)
- **初始驻守 (Alpha)**：3 名普通步兵（分散巡逻） + 1 名塔吊狙击手。
- **增援触发条件 (Trigger)**：交火开始后 30 秒 或 警报器被拉响。
- **第二波增援 (Reinforcement)**：从后方卷帘门冲出 2 名持盾突击兵 + 1 名投掷霰弹兵。
- **环境击杀互动 (Hazards)**：悬挂的钢梁吊钩（可射击绳索砸死下方敌人）、2 处高爆红油桶。
```

## 模板 4：关卡设计全景健康度体检量表 (Level Design Diagnostic Rubric)

当评审一份关卡案或测试实际关卡白模时，对以下 6 个维度进行打分（每项 1~5 分，总分 30 分）：

```
[关卡健康度雷达]
          空间构图 (Architectural)
                   5
                   |
非线性拓扑  5 -----+----- 5  理性度量 (Metrics)
(Topology)         |
                   |
潜意识引导  5 -----+----- 5  遭遇战沙盒 (Arena)
(Guidance)         |
                   5
             节奏张力 (Pacing)
```

| 评估维度 | 5 分标准 (大师级) | 3 分标准 (合格平庸) | 1 分标准 (严重事故) |
| :--- | :--- | :--- | :--- |
| **1. 空间构图与情绪** | 完美运用开阔与庇护，画框构图精准框住地标，空间压迫与释放节奏鲜明。 | 空间有一定高低差，但缺乏画框意识，场景略显单调空旷。 | 纯由方盒子房间与笔直走廊拼接，毫无空间纵深与情绪传达。 |
| **2. 理性度量 (Metrics)** | 所有跳跃、掩体、通道严守尺度，操作容错精准，无任何卡顿或穿模。 | 大部分尺寸合格，偶有跳跃距离极限导致非预期跌落。 | 掩体过低露头被秒、通道过窄镜头乱晃、跳跃落点完全看运气。 |
| **3. 遭遇战与战术沙盒** | 宽线性漏斗结构，提供 3 条鲜明渗透路径，猫鼠脱战回环顺畅，高低差显著。 | 有几处掩体，但只能单向推进，无法重置潜行，只能被动换血。 | 毫无掩体的一维大通铺，全图敌人一秒集火，玩家被堵在门口围殴。 |
| **4. 潜意识光影引导** | 依靠三灯原则、颜色编码与几何箭头，玩家全程无 UI 也能在 5 秒内找到出路。 | 主路径有光，但在岔路口容易犹豫，偶有需要看小地图。 | 光源杂乱无章，亮的地方是死胡同，暗的地方是真出口，玩家疯狂迷路。 |
| **5. 瑞士奶酪非线性** | 空间多层穿孔，包含绝妙的“可见不可达”诱引与单向捷径（Loopback）顿悟回环。 | 有 1~2 处分支死胡同（仅存放小药包），探索略显繁琐。 | 纯单行线走廊或无意义的随机迷宫，折返跑（Backtracking）极度枯燥。 |
| **6. 节奏张力与心流** | 严格遵循锯齿波节奏，每次高压战斗后必有舒缓搜刮区，张弛有度。 | 战斗之间间隔尚可，但高潮点不突出。 | 连续 10 分钟高强度交火无任何喘息，玩家极度疲劳烦躁。 |

### 处方判断基准：
- **总分 $\ge 25$ 分**：当前量表未发现明显结构风险；仍需通过导航、性能、战斗和玩家测试门槛后，才能决定是否进入高精美术资产生产。
- **总分 $18 \sim 24$ 分**：良好，需针对扣分项进行局部微创手术（修光影/补捷径）。
- **总分 $< 18$ 分**：存在结构性缺陷，必须回到白模阶段推倒重构动线。

## 模板 5：防迷路与引导失效外科手术排查清单 (Anti-Lost Checklist)

当玩家在某区域停留超过 $45$ 秒未找到出路时，立刻对照此表排查：

1. [ ] **最高亮度是否偏离主路**：视锥画面中最亮的光源是否打在了无法通行的死墙上？如果是，立刻调暗背景光，将一盏强光投射灯对准出口门洞。
2. [ ] **是否存在视线死角（Blind Turn）**：出路是否隐藏在一个需要转头 $180^\circ$ 才能看到的隐蔽凹槽中？如果是，打通正面墙壁或增加斜向导角。
3. [ ] **缺少视觉面包屑**：转弯后是否有第二盏微光灯或发光收集品接力吸引视线？
4. [ ] **色彩编码混乱**：是否在不可攀爬的黄色管道上刷了与可攀爬物体相同的黄色涂装？如果是，统一材质语义。
