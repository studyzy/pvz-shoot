Audio assets — sources, processing and licenses
==============================================

Every sound effect in public/audio/ was sourced from OpenGameArt.org and
released under CC0 1.0 Universal (public domain dedication,
https://creativecommons.org/publicdomain/zero/1.0/). The original uploads
were downloaded on 2026-10-29.

At runtime these files are not fetched: the embed-audio plugin in
vite.config.js / vitest.config.js splices the raw bytes of each file into
src/fx/audio.js at build time, and Sfx.decodeWav plays them through WebAudio.
The copy under public/audio/ is kept so the assets can be auditioned,
replaced, or re-processed. To replace a sound, edit the file and rebuild.

Processing applied to every file
--------------------------------
- single channel (stereo sources were down-mixed),
- 44.1 kHz, 16-bit PCM WAV,
- silence-trimmed (energy threshold -42 dBFS, 8 ms pad, 12 ms fade in/out),
- peak-normalised to -3 dBFS.
