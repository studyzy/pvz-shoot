# 新地图设计 · 云上发条游乐园

> v1 · 2026-10-31。用户已选定本方向；本文交付完整设计，不代表地图、敌人或模型已经实现。
> 面向现有植物 FPS，保留桌面 / iPhone / iPad 操作、无尽波次与双人玩法。新增参数是原型起点，需实测校准。

## 0. 一句话卖点

**在云海上的巨大音乐盒里，用植物武器对付失控玩具；一枪敲响铜钟，把追兵定格在最滑稽的半步，趁机脱围。**

不是另一片发光森林，也不是工业厂房换上糖果颜色。主题始终是：**一个漂亮、精密、出了小毛病的童话游乐园。**

### 第一眼：从玩家眼睛出发

戴夫站在奶油色拱门下，眼前是宽阔的棋盘广场。正中央，一座 **18 米高的倒挂钟楼**悬在空中：钟面朝下，金色齿轮慢慢转动，下面留出完整战斗空间。左边，旋转木马从大茶杯后露出半个屋顶；右边，红蓝积木搭成夸张的峡谷。远处，一条 **木雕发条鲸**从云海里翻身，腹部小窗依次亮起。

第一只弹簧鸭冲来，脚下提前划出橙色直线。玩家击中旁边的铜钟：铜钟晃动、清脆三音响起，青色刻度环展开；鸭子的一只脚还没落地，突然定格。玩家横移开火，鸭子散成几块软木零件，发条弹起来，阳光球仍按原规则掉落。

**经典**来自音乐盒、木马、胡桃夹子与报时钟；**奇幻**来自云海和倒挂建筑；**奇趣**来自玩具的动作、声音和停机瞬间，而不是堆彩灯。

### 体验目标

1. 进入地图 5 秒内就认得出主地标，截图不需要标题也能区分于森林。
2. 战斗是轻快的“看预兆、换路线、打节奏”，不是在黑暗里找怪。
3. 敲钟即使没有奖励，也有动作与声音的玩具感。
4. 没捡到高级植物、阳光归零时，仍能用免费豌豆完成所有遭遇。

> **From Hindsight memory（夜之森林完整改版：月光童话战场）** — 既有森林已确立月光、族群敌人与地标路线，之前的评审强调先兑现身份和玩法、不要继续堆素材。本案据此选择暖阳玩具主题；当前 `src/world/maps.js`、`NightForest.js` 与森林 v4 文档也确认了这一区分。

## 1. 世界与核心循环

前提：戴夫收到一只走快了的闹钟，误入云上的发条游乐园。报时兔拼命赶时间，把每件玩具都拧得过紧。玩家不是毁掉乐园，而是把失控玩具打散、让音乐盒短暂找回节奏。

| 形式元素 | 本地图定义 |
| --- | --- |
| 玩家 | 戴夫，第一人称；单人或现有双人合作 |
| 目标 | 存活、清波、击败每 5 波出现的报时兔；次目标是选择路线拾取植物 |
| 操作 / 流程 | 原有移动、跳跃、射击、五角色槽；敲钟直接使用射击，不加交互键 |
| 规则 | 敌人技能有场景预警；铜钟局部停机；钟有公共冷却；不暂停玩家 |
| 资源 | HP、阳光、植物弹药、护盾；不增加齿轮币、钥匙或任务道具 |
| 冲突 | 守路玩具、冲撞、抛射、俯冲与 Boss 圈波，需要变换站位 |
| 边界 | 72×72 米的连续实体岛面；无尽波次；外围云海只作远景 |
| 结果 | 沿用死亡 / 双人倒地救援 / 结算规则，退出或重开回到现有流程 |

局内循环：**识别来路 → 选择直路或侧路 → 开火 / 敲钟 → 趁停机脱围或拿补给 → 清波 → 搜刮休整 → 下一波变奏。**

戏剧结构：入口的好奇感 → 玩具失控的滑稽威胁 → 钟声建立掌控感 → 报时兔把节奏推到高潮。无长对白、章节任务、强制教学或新结局。

## 2. 空间：经典环形竞技场，不做漂亮死胡同

### 2.1 总体规格

| 项目 | 设计值 |
| --- | --- |
| 地图 id（拟定） | `cloud` |
| 边界 | `bounds = { x: 36, z: 36 }`，72×72 米 |
| 主战斗核心 | 约 48×48 米；外圈留完整退路 |
| 出生点 | `(0, 28)`，朝 -Z；第一件补给在 `(0, 23)` |
| 中央广场 | 直径约 24 米；钟楼下方可穿越 |
| 主环路 | 净宽 6 米；三条区域侧路净宽至少 5 米 |
| 战斗拐角视线缓冲 | 至少 4.4 米，不在贴脸盲角生成冲撞敌人 |
| 可站矮台 | 0.35–0.40 米；敌人仍能接近并打到玩家 |
| 实体高遮挡 | 2.2 米起，不可直接跳上；装饰顶面不构成可达高台 |
| 主通行拱门 | 净宽至少 5 米，净高至少 4.8 米，Boss 可以通过 |
| 强制跳跃 / 坠落 | 无。跳跃用于躲攻击，而非跨深渊赶路 |

```text
                      北 / -Z
               [北钟 · 发条维修棚]
                  /            \
       [旋转木马街]──[钟楼广场]──[积木峡谷]
            |       /       \       |
        [西铜钟]───/         \───[东铜钟]
            |                       |
       [茶杯花园]────[入口拱门]─────┘
                      出生点
                      南 / +Z

外圈连续回环；木马街、积木峡谷、茶杯花园各有一条接中央的侧路。
任何主战斗区都有至少两条离开路线，不能被单一入口封死。
```

中央钟楼由四组实体支架承托，高处倒挂的是钟面、齿轮和装饰体。**倒挂只改变美术，不改变重力。**木马屋顶与鲸鱼不提供可站表面；地面木马台仅高 0.35 米。

### 2.2 四区必须各有一种剪影与战术

| 区域 | 一眼识别的场景 | 战术身份 / 路线选择 |
| --- | --- | --- |
| 钟楼广场 | 倒挂大钟、棋盘砖、金色刻度 | 视野最好，来敌最容易读；但掩护少、茶壶能逼玩家离开中央 |
| 旋转木马街 | 波浪屋顶、木马剪影、竖向彩旗 | 大体量遮挡切断射线；绕左右两侧打守路敌人，不沿单走廊排队 |
| 积木峡谷 | 红蓝方块高墙、积木拱桥、外露连接钉 | 路线较短，但鸭子的直线冲撞更有压力；侧路能横切离开 |
| 茶杯花园 | 倾斜巨茶杯、勺柄花架、饼干形石砖 | 路线较长、遮挡宽松；强补给位更暴露，需要敲钟或引敌后进去 |

三级地标：18 米倒挂钟楼是全图定位器；木马顶 / 积木拱 / 大茶杯是区域定位器；铜钟和补给的金色小标记是近距目标。高处彩带朝中央弯曲，但不铺满地面箭头。

### 2.3 点位与可达性

十个补给候选点：`(0,23), (0,10), (-20,-8), (20,-8), (0,-24), (-23,14), (23,14), (-12,-19), (12,-19), (-14,5)`。最终白模必须逐点检查净空和流场可达性。

- 第 0 点开局可见，先给普通枪型植物；其余点沿用一关每点只出一次、随机补刷、不原地重生。
- 入口与安全侧路偏普通枪；北侧维修棚、茶杯外缘与积木岔口偏大杀器，使用已有地图 `pickupPools` 接口表达，不加宝箱系统。
- 敌人入口分布在北、西北、东北、东、西区域，第一波距玩家 16–22 米；后续优先选择玩家 12–30 米、非贴脸且有合法路径的入口。
- 不在正在使用的补给点、铜钟正下方或玩家脚边刷怪；候选位置失败时等待，不强塞到墙里。
- 几何、玩家碰撞、僵尸碰撞、弹道墙体同位。平台供玩家解算，实体高墙阻挡流场；禁止对角穿角。
- 云海和栏杆在实体边界之外 / 边缘遮住矩形轮廓。第一版不引入掉落死亡、移动平台或悬空地形。

## 3. 主玩具：射击敲钟

### 3.1 明确的规则

场上三口铜钟放在西 `(-16,3)`、东 `(16,3)`、北 `(0,-17)` 的路旁。钟体可击中区域直径约 **1.15 米**，中心离地 **1.7 米**，不压住通行净宽。

| 参数 | 起始设计值 |
| --- | --- |
| 触发 | 直线弹丸 / hitscan 真正命中铜钟；豌豆可免费触发 |
| 效果半径 | 以钟为中心，三维距离 8 米；声波可穿该范围内的掩体 |
| 停机时长 | 1.6 秒，普通敌人和 Boss 相同，不设 Boss 完全免疫 |
| 冷却 | 三口钟共用 18 秒冷却；双人也共用，不让玩家轮流连锁定身 |
| 受影响对象 | 此地图存活的玩具敌人；死亡回收不被暂停 |
| 不受影响 | 玩家、玩家子弹、已发出的敌方投射物、阳光球和远景动画 |
| 空响 | 范围内无活敌时只响小音、晃钟，不启动停机或消耗公共冷却 |
| 冷却时命中 | 钝响 + 小幅晃动；不刷新状态，不返还武器弹药 |
| 自动瞄准 | 不吸附铜钟，避免从僵尸目标抢准星 |

停机暂停敌人的位移、攻击 / 技能计时及对应动作动画，**解除后从原状态继续，不重置冷却或洗掉蓄力**。飞行纸飞机被停住时仍在空中，不能因此被普通豌豆当成地面单位击中。

已经飞出的茶滴仍然有危险：这不是“时间停止”，而是“机械停机”。茶滴有橙色尾迹，停住的敌人身上出现青色刻度，视觉必须区分两者。

### 3.2 同一个动作解决三个问题

| 玩家目的 | 敲钟带来的局面变化 | 保留的代价 / 选择 |
| --- | --- | --- |
| 战斗解围 | 锁住身边鸭子和守路敌人，换枪、补打或横移 | 只有 1.6 秒；钟不在所有区域，不能永久站桩 |
| 穿路 / 转移 | 暂停窄路追兵，穿到侧路改变追击队形 | 玩家要走到合适的钟附近；敲早了，后来的敌人不受影响 |
| 拿补给 | 冻结守在强补给附近的敌人，抢到植物后离开 | 现在取枪，还是把公共冷却留给即将到来的 Boss？ |

空白场景原型只需要两只鸭、一个钟、两块遮挡物。若拿掉地图装饰后，敲钟仍不能制造有趣的站位选择，就先调机制，不能用更多彩灯掩盖。

### 3.3 起承转合融进正常波次，不另加教学段

- **起 / W1**：铜钟在起始视线旁；鸭子有明显冲撞预兆，正常开打，玩家可以自然发现钟。
- **承 / W2**：两条来路的玩具靠近钟区，敲早 / 敲晚会产生不同收益。
- **转 / W3–4**：茶滴不会停机、纸飞机空中不能被普通豌豆命中；迫使玩家区分“停住敌人”与“消除危险”。
- **合 / W5**：报时兔圈波、鸭子侧路与公共冷却组合。能留钟打 Boss，也能先解围，不设置唯一正确顺序。

无强制弹窗、无 60 秒等待教学、无“必须敲钟才能继续”的门锁。

## 4. 敌人：不是僵尸换颜色

第一版 **五种普通 / 精英玩具 + 一只 Boss**。下表 HP、速度、伤害、分数均为基础值，继续吃项目现有波次倍率；所有模型是待制作的新资产，不能冒充已存在的可用 GLB。

| 胡桃夹卫兵 `toySoldier` | 红白木偶、高帽、可拆漆塑料胸甲；稳定追击，构成正面战线 | 50 / 2.0；胸甲 18 HP | 8 / 90 / 1 | W1 |

### 4.1 读懂危险必须比读血条更快

- **卫兵**：胸甲使用现有 `plastic` 护甲表，吸收 35%，甲血 18；不新增方向盾牌、不偷改火豌豆或穿透特例。胸甲真的可见、破甲脱落；木身体保持卡通木纹。有效体血约 `50 + 18/0.35 = 101.4`，W1 必须验证是否过厚。
- **弹簧鸭**：冲撞前压缩弹簧 **0.65 秒**，显示宽 **1.2 米**、长最多 **6 米** 的橙色轨迹；锁定方向后不追踪玩家，撞实体墙结束，随后 **0.9 秒**摇头恢复。每只攻击间隔至少 **3.2 秒**。
- **茶壶精**：攻击前壶盖跳动 **0.85 秒**；锁定当时地面位置，茶滴速度 **8 米/秒**，落点半径 **0.75 米**，触地只结算一次。无黏液地形 / 持续灼烧；每只间隔 **3.6 秒**，同屏最多 2 只，敌方茶滴全图最多 6 发且撞墙失效。被墙挡视线时沿流场接近，不隔墙抛射。
- **纸飞机**：低飞高度约 **2.6 米**；一个周期为巡航 **4 秒**、俯冲预警 **0.7 秒**、下落 **0.45 秒**、地面恢复 **2.4 秒**、升空 **0.6 秒**。落地才进入可用普通豌豆命中的窗口；不修改其他地图的对空白名单。遵守现有空中配额，地图额外上限 2 只。
- **杰克盒怪**：不是假植物或假补给。盖上的怪脸、呼吸和发条声在远处就可认；拳套出击预警 **0.7 秒**，距离 **2.2 米**，收拳恢复 **1.1 秒**，间隔 **3.8 秒**。第一版无绑人、偷枪、强制镜头或移动控制。

每种敌人死亡最多散出 3 块小木件 / 纸片，走已有粒子池，不保留持久尸骸。声音分别是木脚咔嗒、橡皮鸭短鸣、瓷盖轻碰、纸张扑动、音乐盒错音；威胁声音按距离与声像播放，不全图齐鸣。

### 4.2 报时兔：高潮是节奏，不是超大血条

Boss 每 5 波仅一只，优先排在出生队列前部；专属选择只作用于 `cloud`，不替换森林现有轮换。

**主招：整点圈波。**怀表张开，耳朵组成钟针，地面金色刻度先亮 **0.9 秒**，随后橙色圈从半径 **2 米**扩到 **10 米**，速度 **6 米/秒**。同一目标每圈只结算一次；相对当前位置支撑面的脚底高度超过 **0.35 米**可跳过，否则承受 18 伤害。不能靠站在 0.4 米矮台上永远免疫。攻击间隔 **8 秒**。

**第二招：赶时间冲撞。**锁定一条最多 **7 米**的直线，预警 **0.9 秒**，速度 **4.2 米/秒**，碰到实体遮挡停止；与圈波互斥，不同时堆两个需要跳 / 横移的动作。

**破绽：报错时间。**每次主招结束后 **2 秒**，兔子拍胸口，怀表亮青色，身体伤害倍率 **1.5×**。弱点表现对应已有胸口命中区域，不再加一套独立的精细部位系统；倍率按命中时的有效技能状态裁决。

**50% HP 后变奏**：每次圈波结束 1.2 秒后再报一次；沿用同一预警和速度，不缩短警告。两次完成后进入恢复窗口，场上茶壶数量仍受限。只加组合，不加随机秒杀。

**玩家可选**：用钟暂停蓄力争取撤离；不用钟、读圈跳跃；举坚果吸收伤害但不能开火；绕高遮挡避开冲撞。已发出的圈波不被敲钟倒退或抹掉。

戏剧反馈：兔子被停机时长耳停在半拍，解除时先短促“咔嗒”再续原动作；死亡时怀表恢复正拍、长耳软软垂下，远景鲸腹窗做一次慢速亮灯，不进行全屏闪白。

## 5. 波次、经济和呼吸

### 5.1 前六波

普通单位总量仍取 `waveTotal(n)`；Boss 波额外一只 Boss，与现有数量口径一致。以下是基础方案，不绕过同屏上限。

| 波次 | 普通构成 | 总普通数 | 这一波的主题 |
| --- | --- | --- | --- |
| W1 | 3 卫兵 + 2 鸭 | 5 | 读正面追击与直线预兆；钟在视线旁 |
| W2 | 4 卫兵 + 3 鸭 | 7 | 两路接敌，打散追击队形 |

| W6 | 11 卫兵 + 6 鸭 + 2 茶壶 + 2 飞机 + 4 盒怪 | 25 | 精英拳套开始影响近距站位 |

后续波次在卫兵主场 / 鸭主场间轮换：主力占约 55%，辅攻占余量；茶壶每波最多 4、盒怪每波最多 4，飞机每波最多 2。先保证首次解锁单位登场，再填主辅；每次排列都严格守总量，不能把“每波上限”当成“同屏上限”。

沿用 `waveMaxAlive` 的递增和 14 硬上限；Boss、尸体和新刷入实体也不能挤出硬预算。高波次不得同时启动超过两条普通冲撞 / 俯冲预警；Boss 发圈期间延后普通冲撞启动，但已有投射物继续存在。

### 5.2 不借新地图重做阳光经济

- 初始 60、上限 300、每颗 5、18 秒失效、天降 30 秒一颗全部不变；双人沿用现有 DUO 对应数值。
- 植物仍免费拾取，弹药仍用阳光自动续；豌豆免费、坚果常驻，五角色槽不变。
- 敲钟不掉阳光、不加分、不翻倍击杀收益，不引入新货币或无限刷奖励。
- 这版敌人掉落表是 **候选**，并不声称各波收入已完全等同旧图。前六波基础击杀收入分别约 25、35、65、85、140（含 Boss）、175 阳光。需与每波有效 HP、拾取时机和实际弹药消耗共同检查。
- 首轮测试若发现卫兵胸甲导致免费豌豆清理冗长，优先降低甲血 / 配比，不把敲钟改成伤害倍增器，不靠增加阳光掩盖敌人设计问题。

### 5.3 宏观锯齿节奏

目标序列：`[25, 45, 70, 25, 60, 85, 20]`。它是**体验张力设计分**，不是自动测出的玩家压力，也不与波号一一对应。

对应：初见与读场 → 双路追击 → 抛射混编 → 清波搜刮 → 飞机 / 侧翼变奏 → Boss 高峰 → 恢复音乐盒的低谷。

普通清波休整 **15 秒**，Boss 清波后 **20 秒**；复用小按钮提前下一波，不强迫熟练玩家等满。休整期间不刷追兵，玩家可以走环路搜刮；钟冷却随游戏时间继续恢复，暂停菜单则停。双人提前开波由 guest 请求、host 确认，不各自开下一波。

## 6. 光效、色彩、声音：亮，但不洗白

### 6.1 固定视觉语法

| 用途 | 色彩 / 表现 |
| --- | --- |
| 天空和云 | 奶油白 `#FFF0D8`、浅桃 `#F6C6AE`；云海低于岛面，地平线有层次 |
| 结构 | 暖木 `#9A6244`、旧铜 `#C68A3A`；不做照片级金属反射 |
| 区域识别 | 木马珊瑚红、积木深蓝、茶杯薄荷绿；区域大色块而非散点发光 |
| 危险 | 橙红轨迹 + 方向 / 圈形几何 + 预警声音；不只靠颜色 |
| 停机 | 青色静态刻度 + 停住的发条 + 三音钟声 |
| 补给 | 延续植物自身颜色与金色名称 / 阳光，不与停机青色混用 |

全图童话卡通材质，木纹与瓷花纹是手绘 / 程序纹样，不回到照片式 PBR。敌人轮廓要比墙上的图案更清楚；地面棋盘降低对比度，避免与瞄准和预警抢信息。

### 6.2 三灯构图，不等于三十盏实时灯

- **主光**：一盏暖白方向光，拟定强度 1.8，朝向从左前上方进入；保持钟楼亮面与背面可辨。
- **补光**：一盏天空 / 地面 HemisphereLight，拟定强度 1.4；阴面不黑死，白瓷不过曝。两项强度必须在现有 NeutralToneMapping 下目检校准。
- **引导光**：铜钟、窗户、怀表采用低强度 emissive / 预烘明暗，不为每个窗口放灯。铜钟待机的刻度朝路面收敛，暗示可击中。
- 第一版关闭地图实时阴影，使用接触色 / blob 阴影，维持材料分层。手持植物仍读得出绿色与深浅，不给玩家挂强聚光灯。
- 假光束最多 3 组，放在远景或高处，不横穿战斗准星；不叠大量半透明薄片，不增加 Bloom / DOF / 全屏后处理。
- 铜钟反馈只渲染局部刻度环，1 次低频展开和衰减，无频闪 / 全屏曝光变化。状态边缘从 0.12 秒淡入，0.18 秒淡出。

### 6.3 远景奇趣的成本要可控

木鲸只用一个低面模型、慢速刚体起伏；在边界外固定航路游过，不参与碰撞、伤害或寻路。远景小热气球最多 3 个，共享几何和材质；纸风车与彩旗做少量低频动画，不用布料模拟。

木马屋顶缓慢旋转，地面台座与碰撞不旋转。视觉里有活力，脚下仍然可靠；不要把“旋转木马”顺手扩成移动支撑系统。

### 6.4 声音

复用现有 WebAudio / 采样链路：短钟音与发条咔嗒可合成，受击 / 碎裂复用现有采样做音高变体。不在运行时拉外部音频；若后续采用录音，需 CC0 留痕并按现有构建内嵌流程接入。

底声是低音量风与稀疏音乐盒三音，不持续播完整儿歌、不靠响声逼迫玩家。钟声 / 冲撞 / 壶盖 / 纸扑按优先级让路；同一时刻附近最多突出两个威胁提示，声像指向真实敌人位置。Boss 报时替换局部节奏，不突然放大总音量。

## 7. 手感与计算结果

**不修改现有 `Player`。**依据当前 `TUNING`：速度 5.4 米/秒、起跳速度 7.2 米/秒、重力 21 米/秒²、眼高 1.66 米、半径 0.42 米。

| 量 | 推导 / 校验值 | 采用方式 |
| --- | --- | --- |
| 跳跃顶点 | `7.2²/(2×21) = 1.2343m` | 保留，不能要求玩家跳到 1.4 米台面 |
| 顶点时间 | `7.2/21 = 0.3429s` | 保留 |
| 同高总腾空 | `2×7.2/21 = 0.6857s` | 解析模型，真实步进另验 |
| 最大平地跑跳跨度 | `5.4×0.6857 = 3.7029m` | 理想恒速模型，不拿它当强制关卡跨度 |
| 80% 安全尺度 | `3.7029×0.8 = 2.9623m` | 工具参照；本版无强制跨缝 |
| 拐角缓冲 | 工具建议 4.36 米 | 白模取至少 4.4 米 |
| 张力波形 | 工具判定健康，无连续高压告警 | 只验证序列，不证明实际心流 |

项目没有冲刺、蹲伏、翻越和攀爬。工具预设给出的 4.81 米冲刺跨度、0.91 米低掩体、翻越 / 攀爬参数**不采用**。低台改成 0.35–0.40 米，避免制造近战敌人无法处理的安全高台。

当前水平移动是指数趋近：地面系数 15、空中 12，而非固定加速度。附录的 81 米/秒²是起步瞬间加速度，0.36 米是连续模型松键制动距离，40.5 米/秒²是对该距离的恒减速等效值；仅供契约尺度流转，**不得抄回 Player 改写运动公式**。不新增土狼时间、输入缓冲或全局卡肉停帧。

### 8.2 数据流与安全约束

- 铜钟命中与墙体 / 敌人共同比较弹道上最早交点；墙在前就挡住钟，不能无视墙单独扫一遍铜钟。直线弹丸和 hitscan 都要覆盖；爆炸 / 投掷物第一版不触发钟，避免随手炸一下误用冷却。
- Bell 是新增命中目标，不篡改 `HitWalls` 的通用墙体语义；辅助瞄准仍只找敌人。有效敲钟消耗这一发弹药，免费豌豆仍免费。
- 所有地图 / 敌人参数最终集中 `config.js`，不是在多个系统写同一套 1.6 / 18 / 8。
- 先保留异步模型就绪控制：未就绪单位留在待刷队列、继续尝试合法替代单位，不能清空类型或死等某一只。
- 新模型 Y-up、面朝 +Z、脚底归零；玩具中心 / 头部命中球按真实动作包围盒校准，头球仍小于胸球。几何与贴图共享、每只材质克隆，不 dispose 共享模型。
- 所有地图物体 / 灯归 `root`，切图关闭；不留天空鲸、方向光或敌方投射物在下一张地图。重开清公共钟冷却、敌人技能、投射物和命中历史。
- 地图不新增全屏可点击层；现有触屏视角、开火、跳跃、槽位和安全区保持可用。

### 8.3 双人不是最后才补的一行

guest 的敲钟发送带视线 / seq / 武器信息的请求，host 重算交点、射程与冷却；两人同一帧命中只触发一次。不得把客户端上报的 bell id / 命中 / 时长当作可信结果。

host 快照至少能表达钟公共冷却、各敌人剩余停机时间、新技能状态、纸飞机有效空中状态、Boss 当前动作及血阶段。guest 只显示，不自推伤害 / 停机解除。历史命中使用对应 seq 的姿态和状态；Boss 恢复倍率不能用 host 当前时刻误判历史请求。

茶滴和圈波的生灭 / 目标 / 单次命中也由 host 裁决。既有共享补给与重同步未完成的能力不因新地图假装已经齐备；本案不顺带重写整个联网层。

### 8.4 资产与性能预算（目标，不是实测）

- 六个原创 GLB：普通玩具每只目标 2k–4k 三角面、1–2 个主 mesh / 材质；兔 Boss 目标 8k 面。优先平色 / 顶点色，仅瓷纹和木纹需要小贴图。
- 场景静态主体预算 30k 面；重复积木、栏杆、砖、彩旗实例化。场景目标不超过 55 个主通道 draw call。
- 13 只普通玩具按 4k + 一只 8k Boss = 60k 面；加场景约 90k，给植物 / 粒子 / 远景留出余量。
- 完整游戏主通道目标不超过 200 draw call、150k 三角面；仍保留 14 实体上限、现有 280 粒子池、DPR ≤2 和自动降分辨率。
- 桌面 / iPad / iPhone 60fps 是验收目标，必须分别记录真实设备；软件 WebGL / 模拟触屏不能冒充真机性能。
- 资产来源必须清楚：原创保留 PROVENANCE；若借 CC0 资源，逐项核许可、模型本体和动画，不因文件夹里有素材就声称适合本地图。资源最终放 `public/`，运行时无 CDN。

## 10. 原型与验收，不用设计文档冒充完成

### 10.1 一个核心假设

**面对追兵和补给，玩家是否会主动把敌人带进钟区，并在“现在停机拿枪 / 留钟给更危险的下一拍”间产生真实选择？**

纸面验证：画三个钟区、两条退路，放两枚追兵和一枚补给。每轮玩家选择射敌、移位或敲钟；停机只影响圈内敌人，公共冷却按轮表示。比较有钟 / 无钟时的路线选择，检查是否总在一个点等冷却。它只能测决策，不能验证 1.6 秒手感。

数字白模：真实 Player + 免费豌豆 + 一个钟 + 两只鸭 + 两条路径，先验证最早交点、定格 / 续动、横移窗口；再加入茶壶和报时兔。不要先做全图所有精模。

### 10.2 玩家观察目标（待验证）

首次测试至少覆盖键鼠与真实触屏，观察而非边玩边口述教程：

1. 无弹窗情况下，是否在 W2 前发现钟可射击；目标 ≥80%，失败先调位置 / 尺寸 / 反馈。
2. 同一玩家是否出现解围、穿路、拿补给中的至少两种用途，而非只把钟当定身炮台。
3. 地图辨路是否能靠巨钟和四区剪影完成；每个区域是否至少使用过两条退路。
4. 单纯豌豆能否击杀落地飞机和击败第一只 Boss；失败不得靠放开全图对空规则解围。
5. 统计每波清理时长、掉落 / 续弹、受伤原因、公共钟使用时点；不以“画面漂亮”代替玩法结论。

### 10.3 自动化与真实浏览器最低门槛

实现时必须遵循 AGENTS / TESTING：改代码前 `npm test`，改后全量 UT、原覆盖率门槛、build、真实浏览器 E2E；不修改 CI 管线或降低门槛。

- 地图契约：五图切换、root / 灯可见性、十补给点与全部出生点可达、两退路净空、几何与弹道墙体一致。
- 停机：1.6 秒与公共 18 秒精确边界；空响不耗冷却；两人同时敲一次；墙先命中不响钟；不误停玩家 / 尸体 / 飞出的茶滴。
- 敌人：鸭冲撞方向锁定 / 撞墙、茶滴一次伤害 / 挡墙、飞机空地状态及豌豆窗口、盒怪不冒充补给、破甲显隐。
- Boss：圈波每目标一次、实际支撑面跳跃判定、两招互斥、停机恢复计时、50% 双圈、历史恢复倍率。
- 波次：W1–W6 数量表、每 5 波唯一 Boss、14 实体上限、空中 / 茶壶配额、其他地图的计划与经济不变。
- 联网：guest 不扣敌血 / 自推技能伤害，敲钟请求重算，快照空地与停机一致，重开 / 切图无残留。
- 真实 WebGL：新六模型 / 动画 / 命中区、停机反馈、14 混编预算、敌方弹道、手机横屏与 iPad 真 DOM 输入；保留已有 E2E 场景。
