## 0. 结论先行（TL;DR）

1. **尺度结论：90×90 米起步。** 现网夜之森林已在该尺度稳定运行（1 米网格流场 BFS ≈ 8100 格）；街道网格反而比森林的散点林更适合大图——十字大道把「跑图」变成「沿主干道的快速机动」。再往大（≈104）流场格子数开始翻倍，收益递减，先不做。
2. **高楼的正确打开方式：楼不可爬，层可玩。** MW2 High Rise、Skidrow、BF4 上海之围的经验是：玩法垂直层不在摩天楼顶（引擎无楼梯），而在**裙台 → 天桥 → 楼顶停车场**的 0.95 米级跳链上——本项目跳跃净高 1.234m，Δ0.95 的连续跳链完全成立，且 >0.6m 平台僵尸流场封锁，「玩家专属高线」天然成立。
3. **巷战三线的大图变体**：14 米宽的中央十字大道（开阔远距）+ 环街/横街（侧翼快线）+ 楼间峡谷（主刷怪轴，压迫感最强），叠加**双塔天桥高线**——这是 dust2 三线 × Titanfall Angel City 双层城市 × MW2 High Rise 中央制高点的结合体。
4. **与本项目玩法最同构的参照仍是 L4D2《The Parish》**：街口=刷怪口分组、屋内=喘息阀、高架桥=安全高线但留克制手段（气球可垂直压制高线）。
5. **推荐新图《摩天街区 DOWNTOWN》**（§5）：90×90 黄昏 CBD；玩家守南广场，僵尸沿北「楼峡」主街与东西横街涌入；中央广场纪念碑掩体群争夺；停车楼顶（2.85m）、跨横街天桥（1.9m）与工地平台构成高线网络，最贵战利品放在高线脚下的危险地面点。
6. 实现成本与沙城同级：塔楼=大盒体 + 程序化玻璃幕墙贴图（每栋 1 draw call），街道道具走 InstancedMesh；新增贴图仅 `glassTexture / asphaltTexture / duskSkyTexture` 三个程序化函数。

## 3. 城市巷战地图盘点（按流派分组）

> 评级含义：**S** = 骨架可直接复用；**A** = 关键手法可转译；**B** = 氛围/局部参考；**C** = 仅反面教材或远期参考。

### 3.1 CS 系：欧洲/中东小镇（巷战三线的源头）

#### de_inferno（CS 1.6 → CS2）★★ 本调研头号范本（布局语言层）

- **布局**：意大利式小镇。T 出生 → 三线推进：**香蕉道（banana，弧形下坡直道）**、**中路（mid，花园+公寓阳台）**、**公寓（apartments，室内房间串）**，汇合于 A 点（教堂/圣坛）与 B 点。
- **巷战要点**：
  1. **香蕉道是「曲线走廊」教科书**：弧形 + 拐角让进攻方永远看不到尽头，防守方靠分段掩体逐层设防。
  2. **公寓是「室内第三线」**：房间 3～5m 一间、窗口/阳台朝街，把长枪视线切成 5～8m。
  3. **中路二楼阳台**是标志性的「窗口火力位」：能压制整条中路，但暴露给对面公寓窗口——火力位永远成对出现、互相钳制。
- **可抄锚点**：弧形分段走廊（→楼间峡谷的锯齿裙楼）、成对钳制的窗口火力位。
- **适配评级：A（结构语言层适用一切巷战图，包括高楼街区）**

#### de_mirage / cs_office / de_bank / de_overpass（速览）

- **de_mirage**：中线「短墙 + 窗口」分段法——直街被 2～3 个 0.9m 矮墙切成「跳棋格」。
- **cs_office**：走廊—房间—走廊的「珠串」结构，每个房间 2 个出入口防死堵。
- **de_bank**：天井广场 + 环形回廊，中央开阔区靠少量掩体，四周建筑窗口俯压。
- **de_overpass**：桥上街道 / 桥下涵洞的**双层路线**——快而暴露 vs 慢而隐蔽的二选一。
- **适配评级：B（分段矮墙与珠串结构可用于裙楼内部）**

### 3.2 CoD 系：街区快节奏

#### CoD4「Crash」★★ 单张图讲清「中央高地形」

- **布局**：中东小镇街区。三线（左巷/中街/右楼内），**中央两层楼房 + 天台**是全图心脏。
- **巷战要点**：中央高点「能看全场但全场能看你」——高地不是安全区，是**风险换视野**的交易；街面掩体密度高（车体、箱堆、矮墙每 4～6m 一组）。
- **适配评级：A（高楼图中央广场/裙台的设计依据）**

#### MW2「High Rise」★★★ 高楼巷战的头号范本（详见 §3.7）

#### CoD4 Backlot / Crossfire / MW2019 Piccadilly（速览）

- **Backlot**：中央废楼形成斜向视线，街区网格 + 内部穿行。
- **Crossfire**：一条超长主街 + 两侧骑楼——「长街压制」节奏；警示：主街过长必须用柱阵/矮墙分段。
- **Piccadilly**：街道 + 巴士掩体 + 店面；开阔与遮蔽交替。
- **适配评级：B**

#### MW2「Favela」（警示案例）

- 违章建筑密度爆炸，视线碎到 3～5m——**掩体密度上限的反面教材**：认知负荷过高，迷路率飙升。
- **结论**：本图视线节奏控制在 **8～24m**，掩体密度「每段视线至少一个可借掩体、每条路线至少两个拐角」。
- **适配评级：C（反例）**

### 3.3 PvE 城市僵尸图 ★★ 与本项目玩法同构，优先对标

#### L4D2「The Parish」（新奥尔良街道）★★ 巷战 PvE 的直接模板

- **布局**：线性撤离图：街道段 → 屋内穿行段 → 墓地段 → 街道段 → **高架桥终章**。
- **巷战要点**：
  1. **僵尸成群从街道尽头/岔口涌现**——玩家的「读怪口」训练：街口=刷怪口，建筑门洞=侧翼口。这正是 `zombieSpawnPoints` 分组（主/侧/远）的玩法依据。
  2. **建筑内部穿行提供「喘息阀」**：进屋=暂时脱离街道尸潮，但屋内又是近战劣势位——风险互换。
  3. **高架桥上层 = 安全高线**：桥面视野好、易守，但缺乏掩体且易被特殊感染者针对——高线永远要留克制手段（对应我们的气球）。
- **可抄锚点**：街口刷怪分组、屋内喘息阀、高线+克制、路障窄口。**天桥高线直接对标其终章意象。**
- **适配评级：S（波次节奏骨架可直接对标）**

#### CoD4 单机巷战关（Charlie Don't Surf / War Pig）

- 推进式巷战的「清房—过街—再清房」循环；节奏公式：**开阔街面（尸潮压力）→ 室内/院落（喘息）→ 下一段街面**。
- **适配评级：A**

### 3.4 拟真巷战：院落—街道—天台三层动线

#### Six Days in Fallujah（2023，第二次费卢杰巷战题材）

- **事实核对（Wikipedia，本次唯一成功抓取的页面）**：任务在半开放城市街区进行，玩家逐栋清房、定位目标、夺取据点；强调清房战术、队伍协同与「不确定的敌方隐蔽」；标志性系统是 **Procedural Architecture**——建筑、室内与街道布局每局重新洗牌；开发者引述费卢杰老兵「叛乱分子可能整日持枪守着一个门框」来描述门洞/转角的张力。
- **巷战要点**：① **围墙院落是巷战基本单元**（围墙—门洞—院内开阔—天台通路）；② **明→暗的出入室过渡**本身就是节奏（本项目用雾色/檐下阴影低成本实现）；③ 程序生成对我们不可取（波次生存需要布局记忆），但其**门洞张力**值得保留：门口是最贵的交火位。
- **适配评级：A**

#### Insurgency: Sandstorm（Precinct / Ministry）与 Rising Storm 2「Hue」

- **Insurgency**：据点 A→B→C 链式分布，「阵地转移」节奏——每夺一点防线整体前移一格。**这正是波次生存里「波次阵地逐波前移」的参照**。
- **Hue（顺化皇城）**：城墙顶（高线）与庭院（掩体）成对；窄巷连续掩体。
- **适配评级：A / B**

### 3.5 CQB 室内流派（局部可用）

### 3.7 高楼大厦巷战范本 ★★★（v2 新增，本次主轴）

#### MW2「High Rise」（摩天楼工地）——高楼图的骨架课

- **布局**：摩天楼施工现场：中央**大楼门厅与电梯井**（低层核心）+ 两侧**半成品塔楼与脚手架**（垂直层）+ 施工电梯/吊塔（视觉地标）。
- **巷战要点**：
  1. **低层核心（大堂/电梯井）是全图心脏**：人流汇聚、四面来敌——对应我们的中央广场。
  2. **脚手架与预制板构成「不完全垂直」**：能站上的层都是断续的，站上去必须暴露——垂直层的乐趣在「移动中的高线」，不在「定居高点」。
  3. **工地箱体/管线是天然掩体群**：现代工地语言（箱、板、管）= 低模重复件，与本项目程序化盒体完全同构。
- **可抄锚点**：低层核心汇聚点、断续垂直层、工地箱体语言。
- **适配评级：S（SE 工地象限直接致敬它）**

#### MW2「Skidrow」/「Overgrown」——高密度住宅塔楼

- **Skidrow**：公寓楼围合的院落，消防梯/阳台构成外沿垂直线；视线碎但节奏极快。
- **Overgrown**：高层住宅板楼之间的大院，板楼两端楼道互通。
- **可抄锚点**：板楼沿外沿的阳台/连廊高线（→裙台+天桥链）；板楼围合大院（→四象限街区）。
- **适配评级：A**

#### BF4「Siege of Shanghai」（上海之围）

- **布局**：玻璃幕墙 CBD：跨街广场 + 中央玻璃塔（可进内部 + 电梯升降）+ 三条街桥。
- **要点**：**玻璃塔是「垂直地标 + 玩法核心」二合一**；街道桥面与地面构成双层动线。
- **转译**：本项目无电梯，玻璃塔做纯视觉地标（黄昏发光窗），玩法层用裙台/天桥替代电梯层。
- **适配评级：A（视觉基调范本：本次地图的玻璃幕墙 + 黄昏发光窗直接取材于它）**

#### 汇总：高楼图的四条铁律

1. **摩天楼本体永远是纯视觉/碰撞体**（引擎无楼梯）——玩法垂直层全部落在 **0.95 米级跳链**上（裙台→天桥→楼顶停车场）。
2. **高线必须「断续」**：像 High Rise 的脚手架，站上去的每一层都暴露，气球随时垂直压制——移动中的高线 > 定居高点。
3. **街道峡谷是主战场**：14m 主轴 + 8m 横街的网格天然形成「压迫走廊 + 侧翼快线」。
4. **玻璃幕墙/霓虹是廉价氛围**：1 张程序化发光窗纹理 + 雾色就能出「黄昏 CBD」，1 draw call/栋。

## 4. 巷战布局法则提炼（含高楼特化）

### 法则 C1：锯齿街道——用凸出体量打断长视线
- 直街每 8～12m 用一个**凸出的裙楼/门楼**制造拐角；最长视线控制在 18～24m（5.4 m/s 下 ≈3.3～4.4s 反应窗）。

### 法则 C2：室内第三线——裙楼内廊/骑楼
- 主街一侧贴一排「商铺体块」，内部挖 2.4～2.6m 内廊，两端 3～3.2m 门洞；近战快线 + 尸潮喘息阀 + 拾取藏匿位。

### 法则 C3：院落节奏——窄口→开阔→窄口
- 每个街区单元 = 围墙/楼体（≥2.2m 不可跳）+ 3～3.6m 口 + 院内 12×14m 开阔 + 对侧出口；波次缓冲舱。

### 法则 C4：窗口与阳台——成对的火力位
- 火力位永远**成对且互相钳制**：本项目转译为 0.95m 窗台/裙台 + 视线互通的对位设计；不给「只有一个方向能被打」的射击孔。

### 法则 C5：高线——玩家专属，但必须可被克制
- 高线链：0.9 箱 → 0.95 台 → 1.9 天桥/裙台 → 2.85 楼顶（每级 Δ0.95）。僵尸流场封锁，气球可及。
- 反无敌点三件套：无顶棚、至少两面在僵尸射界/气球范围内、高点放**高价值拾取**逼玩家冒险。

### 法则 C6：街区块节点——十字街口是动线枢纽
- 街区网格的十字路口是天然「转点枢纽」：到达任一街口的 3 秒内应有 ≥2 条可选路线。
- 中央广场不要空旷：用 4～6 个可绕体块（纪念碑/毁车/花坛）拼掩体群。

### 法则 C7：刷怪口=建筑口——把涌入方向写进立面
- 主刷怪口给楼间峡谷口（≥6m）、车库门（3.6m）；侧翼给横街口与工地门；远端给环街角。
- 玩家应能**从立面读出**「这里会出怪」：车库门挂门框色带、巷口挂路灯、工地口用警示黄纹。

### 法则 C8：波次阵地前移——据点链式节奏
- 借鉴 Insurgency 据点链：波 1～3 守南广场 → 波 4～7 推到中央广场 → 高波/Boss 波反攻北峡谷或借高线游击。

### 法则 C9：掩体密度梯度
- 街面密（每 4～6m 一组矮掩体）、广场疏（中央 2～3 组硬掩体）、街区内中（1 组 + 楼体借掩）。
- 反例见 Favela：密度上限 = 「每段视线一个可借掩体、每条路线两个拐角」。

### 法则 C10：明暗交替与三级地标
- 街面（亮）→ 裙楼廊/街区院内（暗）交替，用雾色 + 檐下阴影实现（Fallujah 条目）。
- 地标三级：双塔（宏观灯塔）/ 天桥·纪念碑（区域中地标）/ 灯柱·花坛·邮筒（拐角微诱饵）。

### 法则 C11：高楼分层转译（v2 新增）
- 摩天楼本体 = solid 大盒体 + 幕墙纹理，高度 12～22m 只做视觉与弹道墙。
- 玩法垂直层 = **Δ0.95 跳链**：地面 → 路缘台 0.4 → 裙台 0.95 → 二层裙台 1.9 → 楼顶 2.85。
- 每条跳链两端各留一条地面路线（不能让高线成为唯一通路）；高线穿过街道上空时做成**天桥**（视觉+玩法双收）。
- 所有垂直层登记 `walls` 投掷物体；栏板 ≤0.5 且 `collide:false`（沙城 A 点矮台先例），保证射界。

### 5.7 高线网络（玩家专属 + 反无敌点）

- 三条链：**天桥线**（商场台阶箱 0.95 → 商场裙台 1.9 → 天桥 1.9 平接 → 工地板台 1.9）、**停车楼线**（楼梯台 0.95 → 1.9 → 2.85 楼顶）、**工地线**（箱两级 0.95/1.9 → 板台 1.9）。
- 悬空板脚印是玩家地面禁区（`pushOutOfPlatforms` 水平推出）：天桥 footprint 只占横街 x∈[22,30]，两侧各留 6m 地面通道。
- 全部 >0.6m → 僵尸流场封锁；停车楼顶与楼峡正下方都有刷怪纵深。
- 所有高线层无顶棚、栏板 ≤0.5 且 `collide:false`，四面至少两面在地面射界内；跳链两端必有地面绕行路线（高线不是唯一通路）。

**克制机制（定稿，终轮实测修正）**：原稿「气球照常垂直压制高线」是**假命题**，实测推翻——气球 `airHeight = 2.2` 恒高不俯冲，撕咬判定要求它与玩家脚底的垂直距 `dy ≥ 1.6`；玩家站上 1.9 天桥 / 2.85 停车楼顶后 `dy ≤ 0.65 < 1.6`，气球**咬不到任何高线**（地面玩家 `dy = 2.2 ≥ 1.6` 才在它的咬合包线内）。因此高线的真实制约只有两条：

1. **阳光经济**：击杀掉落全部落在地面（掉落点 = 尸体位置），阳光球 18s TTL——蹲楼顶等于切断击杀收入，只能靠天降阳光（30s 一颗）与楼下队友（单人局没有队友）。高线是「换视野让收入」，不是安全屋。
2. **台缘暴露**：高线层无顶棚、栏板 ≤0.5 且不挡人，四面台缘都在地面射界内；楼峡/横街的僵尸纵深从两侧持续施压，玩家必须在台缘探头射击。

把拾取物搬上平台需要改 `WeaponPickups` 引擎（点位高度采样 + 玩家登台触发）与全图拾取契约（`platformAt ≥0.6 禁止点位`），本轮**明确不做**；高线收益维持「视野 + 安全」两项，经济代价由玩家自觉权衡。

### 5.9 风险清单（实现前逐条核对）

1. **悬空板脚印=玩家地面禁区**：`pushOutOfPlatforms` 会把脚底低于台面的玩家水平推出脚印——天桥 footprint 只占横街 x∈[22,30]，两侧 x∈[16,22] / [30,37] 各留 6m 通道；僵尸流场同理绕行（blocked + 0.55 padding 后仍有 ~5m 走廊）。
2. **圆碰撞**：薄墙沿 `blockColliders` 规则（r=0.68、间距 1.1）；街区楼体门口错位，防 BFS 穿角。
3. **Boss 卡位**：所有门洞 ≥3m（Boss 半径 0.9）；楼峡口 14m、商场口 3.6m、工地口 3.2m。
4. **投掷物**：门楣、天桥体、栏板、塔楼挑檐全部登记 `walls`（沙城 lintel 先例）。
5. **性能**：塔楼每栋 1 个大盒 + 程序化幕墙纹理（≤180 draw calls、≤20 万三角面；沙城实测 100～130 DC 为基准）；灯柱/花坛/护栏/空调外机走 InstancedMesh；幕墙不开投影。
6. **远端刷怪延迟**：环街远端点行进 ≈30s，实现时用 `waveSpawnInterval` 错峰验证，必要时并入侧翼组。
7. **程序贴图**：materials.js 新增 `glassTexture / asphaltTexture / duskSkyTexture`；不引外部图片（AGENTS §5.8）。
8. **双人**：南广场宽 12m，`duoSpawn ±1.8m` 安全。

6. **灯柱 ±42.4**：环街灯柱线从设计外沿用 ±42.4——刷怪落点 clamp 到 ±43.8 后还有 clearOfColliders 二次 clamp，若灯柱贴 ±43.2（距 clamp 线 0.6 < 推离 1.4），贴边落点会被夹回灯柱推离圆里。
7. **建筑 cap 关闭**：`solid()` 不加顶盖（cap）——所有可站平台的顶面高度即平台顶面（裙台/天桥/板台 1.9、停车楼 0.95/1.9/2.85），加盖会让顶面高度与 platform 表不一致。

9. **休整时长**：§5.8 节奏落地时按 FOREST 先例接入 `config.DOWNTOWN = { intermission: 9, bossIntermission: 14 }`——90×90 图「广场→楼峡中段 32m/5.9s」的反攻走位需要比默认 6.5s 更长的整备窗口。
