## 1. 决策空白诊断（为什么是这些内容）

| # | 空白 | 现状证据 | 本案的解 |
| --- | --- | --- | --- |
| 1 | 敌人全是近战直线怪 | 全部僵尸 `update` = 追玩家 + 贴脸挥击；背靠墙即安全解 | 甩泥僵尸（远程压制）、掘地僵尸（钻地绕后） |
| 2 | 波间 6.5 秒纯等待 | `waveGap` 期间无任何玩法 | 陷阱槽：埋雷/铺刺/种食人花的准备窗口 |
| 3 | 所有武器都是扣扳机 | `tryFire` 只有 pea/lob/hitscan 三分支 | 陷阱 = 部署型动词；放置即决策 |
| 4 | 威胁同质、无击杀优先级 | 先杀谁无所谓，DPS 均匀泼即可 | 舞王（必须先死）、甩泥（该先死）、读报（别磨血） |
| 5 | Boss 无机制 | AGENTS.md §8 自认「只有高血量/高伤害/大攻击距离」 | 伽刚特尔砸地+扔小鬼；僵尸博士三技能循环+落地窗口 |

**设计纪律**（继承 economy-v3）：
- 阳光是唯一货币，天降/击杀是唯二水龙头——陷阱**不产阳光**，只花阳光
- 平衡靠 `ARMOR_MATERIALS` 表推导，不写武器×僵尸的特例
- 对空白名单三处一致（`ProjectileSystem` / `WeaponSystem` / `damageArea`）
- 移动端性能预算不动：同屏 14 上限、draw call 不净增

## 2. 陷阱槽（第 6 角色槽）

### 2.1 槽位与输入

- `SLOT_KEYS` 追加 `{ role: 'trap', label: '陷阱' }`，`SLOT_KEY_BASE = 1` 不变 → 数字键 **6**；Tab 循环、Backspace 丢弃自动覆盖（现有管线零改动）
- 触屏 `slot-dock` 从 5 格变 6 格（横排不变，一格约窄 8%——CSS 单处调整）
- 陷阱和枪一样是**地面拾取物**：进 `lootIndices` 随机池（自动生效，`makeMini` 通用）、按 `slot: 'trap'` 入第 6 槽、同槽再捡顶掉旧包
- 陷阱槽**不设常驻保底**（豌豆是唯一承重墙，别动）

### 2.2 通用规则（四株共用）

| 规则 | 内容 | 理由 |
| --- | --- | --- |
| **放置动词** | 切到陷阱 → 左键在**准星落点**放置（复用 `groundRange()`，但钳制在 **2~8 米**） | 与枪械共用输入；近放是技巧（风筝中埋脚下雷），远放是白给（防 22 米外安全埋雷） |
| **充能模型** | 完全复用弹匣制：包 = `ammo` 颗，放置扣 1 颗，打空自动 `tryReload()` 扣 `cost × ammo` 续满；阳光不够 → `locked` 变灰「缺阳光」 | 经济 v3 原样套用，零新经济代码 |
| **场上上限** | 每种陷阱独立 `maxActive`（雷 3 / 刺 2 / 窝瓜 2 / 食人花 1），触顶后再放置 = 拒绝音效 + 抖动 | 性能与平衡双保险，全场陷阱实例 ≤ 8 |
| **放置冷却** | 每株独立冷却（防 3 颗雷 1.5 秒内全倒） | 见分株表 |
| **不可被攻击** | 僵尸无视陷阱（不撞、不打、绕也不绕） | 僵尸 AI 零改动；陷阱的价值全在「提前布置」 |
| **关卡重置** | `reset()` / `setMap()` 清空全部场上陷阱与未就绪状态 | 与 WeaponPickups 一致 |

#### 土豆地雷（Potato Mine）——便宜的爆发

| 反制场景 | 通道口、玩家风筝路径、脚下自保圈 |

#### 愤怒的窝瓜（Squash）——触发式清群

| **愤怒机制** | 触发瞬间圈内 ≥ 3 只 → 伤害 ×1.5（480）——窝瓜越挤越气，图标冒蒸汽 | 
| 放置冷却 / maxActive | 8s / 2 |
| 定位 | 雷=单点爆发、刺=持续封锁、**窝瓜=聚堆惩罚**；对读报僵尸（报纸期 190 血）一发带走 |
| 反制场景 | 舞王召唤的小鬼群、巨人扔下的小鬼落点、任何 3+ 聚堆 |

#### 食人花（Chomper）——哨兵处决

| 项 | 值 |
| --- | --- |
| 包大小 / 续包价 | 1 株 / 30 阳光 |
| 生根时间 | 0.8 秒 |
| 触发 | 僵尸进入半径 1.5m |
| 效果 | **当前血量 ≤ 450 的僵尸整只吞掉**（秒杀，无视护甲——吞是吞，不是打）；对高血目标（铁桶半血以上/Boss）改为咬 350 伤 |
| 咀嚼 | 吞/咬后咀嚼 9 秒（垂头、无攻击力），之后复位 | 
| 放置冷却 / maxActive | 10s / 1 |
| 定位 | **处决器 + 保险丝**：摆在玩家侧后 2 米，追你的残血僵尸自己走进嘴里；「当前血量」判定让它天然是补刀位 |
| 反制场景 | 残血铁桶/骷髅冲脸时的救命口；对 Boss 只有 350 咬——别指望它打 Boss |

### 2.4 陷阱经济自检（防「陷阱流通关」）

- 最贵组合全下：45+40+50+30 = **165 阳光**（≈ 33 只普通僵尸的掉落），且窝瓜/食人花是一次性消耗
- 陷阱**零阳光产出**，纯消耗；甩泥僵尸 8~14 米外点名单兵拆陷阱节奏（逼你出门处理）
- 伽刚特尔 2200 血：3 颗满伤雷 = 2700 理论伤，但它走得慢、绕着走，实战命中 1~2 颗——**雷区杀不死 Boss，只削一层皮**
- 结论：陷阱是「用阳光买地形优势」，不是替代射击的第二主输出

### 2.5 工程坐标

| 改动 | 位置 | 说明 |
| --- | --- | --- |
| 4 株武器条目 | `config.js` → `WEAPONS` **数组末尾追加**（硬规则：下标敏感） | 新字段：`slot:'trap'`、`kind:'deploy'`、`trap:{ armTime, triggerRadius, blastRadius, damage, maxActive, placeRange, … }` |
| 槽位 | `config.js` → `SLOT_KEYS` 加 trap 行 | `SLOT_KEY_BASE=1` 不动，自动变 6 号键 |
| 放置分支 | `WeaponSystem.tryFire` 加 `kind === 'deploy'` 分支 | 调 `groundRange()` 钳制 2~8m → `ctx.traps.place(id, point)`；放置成功扣 1 弹药走通用路径 |
| 视图模型 | `WeaponSystem.buildViewModels` 的 `builders` 补 4 个分支 | 手持是「一袋雷/一捆刺」的小道具，复用 `makeMini` 几何 |
| 落点预览 | 新增放置 ghost：地面光圈 decal（绿色可放/红色超限） | 场景内 mesh 非 DOM；切到陷阱槽才显示 |
| **新系统** `src/entities/TrapManager.js` | 仿 `WeaponPickups` 池化：`place/update/reset`；update 内做布防计时、触发检测（遍历 `zombies` 脚底距离）、到时枯萎、FX 回调 | **不改 `Zombie`**——触发是陷阱主动量距离，僵尸无感知 |
| 更新顺序 | `Game.update` 里插在 `projectiles.update()` **之后** | 用当帧僵尸位置；在阳光球之前无依赖 |
| HUD | `slot-dock` 第 6 格；弹药数即剩余颗数（现有 ammo HUD 通用）；`HUD.ICONS` 补 4 图标 | 触屏横排 6 格 CSS 收窄 |
| 测试 | UT：布防/触发/枯萎/上限/续弹；E2E：`__game.weapons.pickup(N)` 后按键 6、`__game.traps.items` 断言 | `tests/unit/` 新增 `trapmanager.test.js` |

性能：全部池化 + 8 实例上限，InstancedMesh 可选（P1 先普通 mesh，量小无所谓）。

## 3. 新僵尸

### 3.1 P1 三种（纯行为+配件，零新系统）

#### 小鬼（Imp）——最快的炮灰

| 项 | 值 |
| --- | --- |
| hp / 速度 / 伤害 | 35 / **3.4 m/s（全场最快）** / 6 |
| 体型 / 分数 / 掉落 | 0.7× / 50 / 1 颗（5） |
| 行为 | **之字包抄**：前进方向叠加横向正弦（幅 0.8m、2.2Hz），散开包抄而不是排直线 |
| 出场 | ① 波次常规：第 7 波起 `floor((n-6)×0.9)` 只、单波上限 6、**同屏配额 25%**（14 只时 ≤3，仿 `AIR_QUOTA_RATIO` 机制）② 舞王/伽刚特尔召唤 |
| 模型 | zombie.glb scale 0.7，无配件，2 draw call |

#### 甩泥僵尸（Mud Lobber）——第一个远程

| 项 | 值 |
| --- | --- |
| hp / 速度 / 伤害 | 110 / 1.4 m/s / 泥球 10（近战 9） |
| 分数 / 掉落 | 300 / 2 颗（10） |

### 3.3 新护甲材质（进 `ARMOR_MATERIALS`，表驱动不变）

| 材质 | 谁用 | absorption | burnImmune | pierceBlock | 一句话 |
| --- | --- | --- | --- | --- | --- |
| `paper` | 读报的报纸 | **0.85** | **false（可燃）** | false | 纯挡刀盾：85% 吸收让报纸期几乎不掉血，但火豌豆 `armorBreak ×2` 一秒烧穿——报纸的正确钥匙就是火 |
| `screen` | 铁门 | 0.55 | **false（可燃）** | **true** | 铁桶的镜像：少 15% 吸收但可燃；挡穿透（门是网格，仙人掌打不穿） |

> 推导示例（无一条是特例）：火豌豆 vs 读报 = 烧报纸快 → 触发暴怒早晚的节奏账；仙人掌 vs 铁门 = 穿不透；爆炸 vs 铁门 = 照常 45% 进血。全部从表里长出来。

### 4.1 Boss 轮换表（`BOSS_CYCLE`）

| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Boss | 伽刚特尔 | 巨型骷髅 | 伽刚特尔 | **僵尸博士** | 伽刚特尔 | 巨型骷髅 | 伽刚特尔 | **僵尸博士** |

- 巨型骷髅（现有 `boss`）**原样保留**进轮换
- 僵尸博士每 20 波登场一次，是「阶段考」：第 20 / 40 / 60 波
- Boss 出现时机维持现状（波内随机时点）；Boss 波横幅加 Boss 名字与专属配色
- Boss 血量照常吃波次倍率（`zombieHpMul`），但三只 Boss 基础血按登场波校准（见 4.5）

### 4.2 伽刚特尔（Gargantuar）——力量型

| 项 | 值 |
| --- | --- |
| hp / 速度 | 2200（第 5 波实际 ≈ 3168） / 1.1 m/s |
| 体型 / 攻击距离 / 分数 / 掉落 | 2.6×（≈4.8 米）/ 2.6m / 3000 / 10 颗（50） |
| 模型 | zombie.glb scale 2.6 + **电话线杆**（`acc:'pole'`，`buildHat` 分支：右手握杆）——**2 个 draw call，比巨型骷髅便宜 4.5 倍** |

**技能一：重锤砸地**（替换普攻）
- 进入 2.6m → **0.8 秒前摇**（举杆过顶 + 脚下红色警示圈 decal）→ 砸落：半径 1.8m、**32 伤 + 击退 3 米 + 镜头震动**（复用 `applyShake`）
- 前摇就是走位窗口——会打的玩家一次不吃，不会的玩家被赶着跑

**技能二：甩小鬼**（半血杀招）
- 首次降到 50% 血 → 抬杆把 1 只小鬼**抛物线砸向玩家当前位置**（复用 `throwCherry` 的落点解算，落点=玩家实时坐标）；之后每再损 25% 血多扔 1 只，单场 ≤ 3 只
- 小鬼落地无伤害，落地即进入之字包抄——**脚下预埋土豆雷是这个时刻的教科书解**

**反制**：寒冰风筝、雷区削皮、拉开距离磨（1.1 m/s 全场最慢）、爆发武器（机枪/玉米炮）砸前摇窗口。

### 4.3 僵尸博士（Dr. Zomboss）——机制型·阶段考

| 项 | 值 |
| --- | --- |
| hp / 分数 / 掉落 | 2000（第 20 波实际 ≈ 5980） / 5000 / 14 颗（70） |
| 形态 | zombie.glb scale 1.5 坐进**悬浮机甲盆**（`acc:'zombot'`：程序化玻璃罩 + 金属盆 + 喷口光晕）；悬停 **2.4 米**（复用 `airborne/airHeight`，命中球抬高 ×1.3） |
| 移动 | **环绕**：以玩家为圆心 10~14 米距离带绕圈（速度 3.2 m/s，每 3~5 秒换环绕方向），不追不贴 | 

**技能循环**（每 4 秒决策一次，加权随机）：

| 技能 | 内容 | 反制 |
| --- | --- | --- |
| 🔥 **火球** | 直线弹道 14 m/s、18 伤（复用 `EnemyShots` 池） | 侧移即躲（弹道有 0.5 秒飞行时间） |
| 🪂 **空投小鬼** | 玩家周围 3~6 米随机点空降 2 只小鬼（出生动画：从 3 米高落下拍地） | 窝瓜/地刺预收过路费 |
| 💥 **俯冲**（冷却 ≥ 12 秒） | 锁定玩家当前位置直线冲刺（25 伤 + 击退）→ **冲完趴地 2.5 秒「过热装填」**：降到地面、机体冒蒸汽、**受击 ×1.5 且所有武器都能打到** | 冲完立刻转身输出——攒了一整轮的玉米炮弹药就等这几秒 |

**高度机制**（与气球同规则、三处一致）：
- 悬浮期：只有对空白名单武器有效（爆炸类全伤、火豌豆 0.25 倍、仙人掌无钥匙、站 ≥1.5 米高台通用解）
- **过热窗口**：落地 = 失去空中身份，豌豆机枪全部生效 ×1.5
- 这制造了本作第一个「**弹药管理 × 时机**」的 Boss 战节奏：博士在天的 12 秒你存钱存弹，趴地的 2.5 秒倾泻

**工程坐标**：
- `ZOMBIES.zomboss`：`airborne:true, airHeight:2.4, orbit:{min:10,max:14,speed:3.2}, bossAI:'zomboss'`
- `Zombie.update` 加 `orbit` 移动分支（不追人，绕圈）+ `bossAI` 状态机（`hover → dash → overheat → hover`，攻击计时器独立于移动）
- 俯冲落点 = 冲刺直线终点，`dash` 期间 `airborne` 临时置 false → 三处命中口自动放行（**不需要写第四处特判**——这是把「落地窗口」做进现有对空管线的最省路径）
- 过热视觉：粒子蒸汽（`Particles` 现成接口）+ 机甲红光 `emissive`
- 伽刚特尔侧：`ZOMBIES.gargantuar` + `slam:{telegraph:0.8, radius:1.8, knockback:3}` + `impThrow:{at:0.5, per:0.25, max:3}`；砸地走 `damageArea` + 击退向量写进 `Player`（新增受击冲量接口，一次性）

### 4.4 巨型骷髅（现状保留）

数值、木棒、命中口径全部不动；唯一变化是进轮换表（`BOSS_CYCLE[1]`）。它代表「纯坦克型」，伽刚特尔代表「力量型」，博士代表「机制型」——三种 Boss 性格分明。
